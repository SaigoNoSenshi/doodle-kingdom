# Doodle Kingdom

A coloring, drawing, tracing and music app for kids, built to run on a tablet or phone.

**Play it:** https://saigonosenshi.github.io/doodle-kingdom/

- **Photo Magic** — turn any photo into a coloring page, entirely on the device
- **Doodle Library** — 36 original line-art pages across 12 themes, including a Filipino Fiesta set
- **Doodle Machine** — endless procedurally generated monsters, mandalas, mazes, dot-to-dot and color-by-number
- **Tracing School** — A–Z, a–z, 0–20, ABAKADA, shapes, words and your own name, with star scoring
- 18 art tools, stylus pressure, mirror painting, shapes, text, frames and a drawing replay
- **Music Corner** — 8 original songs, your own songs from the device, plus xylophone, piano and drums
- Bilingual English / Filipino throughout, with spoken words
- Saves artwork to the device, works offline, installs to the home screen

Everything is one self-contained HTML file. No accounts, no tracking, no network calls —
photos never leave the device.

## Install

- **iPad / iPhone**: open the link in Safari, tap Share, then *Add to Home Screen*
- **Android**: open in Chrome, tap the menu, then *Install app*
